### 数学迁移中的明确变化

- C 的环绕误差现在与 C++ 一致，支持跨多个周期；半周期点保留误差符号。旧实现只修正一次周期，因此极端输入不保证旧结果逐位相同。
- AHRS 归一化使用标准 `sqrtf`，去掉 `long*` 类型重解释。零或无效平方范数返回零归一化系数，避免零梯度产生 `0 × infinity`；磁场水平幅值直接用 `sqrtf`，避免零水平场的除零路径。
- 角度转换常数使用同一个 π 定义。AHRS 归一化精度和浮点舍入会与旧近似实现有细微差别，需要后续板级验证。
- PID 的积分和 anti-windup 控制律本批没有改写；旧 C PID 参数类型仍由现存设备控制器使用，尚不能删除。
