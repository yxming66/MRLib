# 统一底盘模块

`chassis.hpp` 是面向应用的统一底盘控制入口。应用只选择运动学模型并提供四个 `WheelDevice`，不需要知道模块内部使用的是麦轮还是前全向后麦轮。

## 控制周期

固定周期中按以下顺序调用：

```text
UpdateFeedback -> SetCommand -> Step(dt_s) -> CommitOutput
```

`Step` 必须在成功的 `UpdateFeedback` 后调用一次；一次反馈只允许计算一帧输出。`CommitOutput` 只提交待提交输出一次。控制周期 `dt_s` 必须在 1 微秒到 100 毫秒之间，超出范围时模块进入故障状态。

返回 `kFault` 后，应用应记录故障。若所有设备能成功执行 `Relax`，调用模块的 `Relax()` 可清除控制状态并回到已注册状态，再由应用决定是否重新使能；若设备不能安全停机，模块保持故障状态。

## 设备接口

`device/wheel/wheel_interface.hpp` 定义模块需要的最小能力。它采用 `int8_t` 返回值以兼容现有嵌入式设备 API；返回 `0` 表示成功，非零表示设备错误。接口不拥有设备对象，也不负责设备的内存分配。

当前的 `RmM3508Wheel` 已提供该接口的适配实现。其他电机型号只需要实现同一接口，即可复用底盘模块和运动学。
