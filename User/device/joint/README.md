# 通用关节传动

项目持有电机、`MotorActuatorAdapter`、`JointT`，按此顺序构造，生命周期从右向左结束。独立关节可作为 `IActuator` 直接绑定到通用 `Arm<N>`。关节不选择电机型号，不读取遥控，不初始化板级硬件。

`a = s*q + b`：a 为电机适配器输出坐标，q 为关节坐标，s 为非零传动系数（负值表示反向），b 为传动偏置加标定偏置。旋转关节单位为 rad，移动关节为 m；混合单位时 s 自带对应量纲。位置/速度按此映射，转矩/力按虚功守恒映射：反馈 `tau_q=s*tau_a`，指令 `tau_a=tau_q/s`，MIT 增益除以 `s²`。

独立关节执行 `Update → SetMIT/SetTorque → CommitControl`。配置变化或反馈失效会清除待发命令。位置控制裁剪到关节限位；力矩模式的限位、使能和停机策略由控制模块/应用负责。应用必须处理全部返回值。

耦合传动通过 `AddCoupling(source, coefficient)` 声明 `a_i=s_i*q_i+Σ(c_ij*q_j)+b_i`，由 `JointGroup<N>` 统一处理。组内必须包含所有依赖，不能共享执行器，也不能有循环依赖。`UpdateFeedback()` 先采集全部执行器，再按拓扑顺序解算坐标；力矩反馈用完整 `Jᵀ*tau_a`。`SetTorques()` 解算 `Jᵀ*tau_a=tau_q` 后统一暂存；组内单轴耦合 MIT/力矩接口返回不支持，防止遗漏交叉作用力。

组的 epoch 表示同一次反馈轮询，并不保证各 CAN 帧在同一时刻采样。项目应按控制带宽额外检查各执行器的时间戳偏差；帧龄由 motor 层检查。耦合组目前供应用显式调度，不可把每个耦合 `JointT` 分别绑定到会逐轴调用 `Update/SetMIT` 的 `Arm<N>`。需要耦合机械臂控制时，应由应用/后续专用输出策略产生完整关节力矩向量。

暂存不是发送。RM 类型最终仍需应用调用其共享 `RmCommandBus::Flush()`，包括控制错误和 Relax 分支。
